# Quick Start Guide - Multi-Player Rooms

## For the Host (Creating a Room)

1. **Start a Game**
   - Click "Create World Game" or "Create India Game" from the main menu
   - Select your preferred time control (Blitz, Rapid, Classic, or Unlimited)

2. **In the Lobby**
   - You'll see a 6-character room code (e.g., "ABC123")
   - Click the "📋 Copy" button to copy the room code
   - Share this code with friends via text, Discord, etc.

3. **Wait for Players**
   - Watch as players join - you'll see them appear in the grid
   - The player count updates automatically (e.g., "Players: 3/8")
   - You'll have a crown icon 👑 showing you're the host

4. **Start the Game**
   - The "Start Game" button appears when at least 2 players have joined
   - Click it when everyone is ready!
   - Game will begin after a 2-second countdown

## For Players (Joining a Room)

1. **Get the Room Code**
   - Ask the host for their 6-character room code

2. **Join the Room**
   - Enter the code in the "Enter Room Code" field on the main menu
   - Click "Join"

3. **Wait in Lobby**
   - You'll see all other players in the room
   - Your card will have a green border
   - Wait for the host to start the game

4. **Game Begins**
   - When the host starts, everyone will begin playing together!

## During the Game

- **Live Scores**: See everyone's score update in real-time at the top
- **Your Progress**: Make your guesses as normal
- **Auto-Advance**: When all players finish a round, the game automatically moves to the next round
- **Leaderboard**: Players are always sorted by current score

## After the Game

- **Final Rankings**: See where you placed among all players
- **Full Scoreboard**: View everyone's final score
- **Back to Menu**: Click to return and play again!

## Tips

- **Room Capacity**: Rooms support up to 8 players by default
- **Time Control**: Everyone plays with the same time limit per round
- **Fair Play**: Everyone gets the exact same locations to guess
- **Leave Anytime**: Players can leave the lobby before the game starts
- **Reconnect**: If you disconnect and rejoin with the same code, you'll rejoin the game

## Troubleshooting

**"Room not found"**
- Check the room code for typos
- Ask the host to verify they shared the correct code
- The room might have already started or been deleted

**"This room is full"**
- The room has reached maximum capacity (8 players)
- Ask the host to create a new room

**"This game has already started"**
- You tried to join after the game began
- Wait for the current game to finish or ask for a new room code

**Game won't start**
- Host needs at least 2 players to start
- Make sure the host clicks the "Start Game" button
